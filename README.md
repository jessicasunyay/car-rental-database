# Car Rental Database
An end-to-end relational database application built on IBM DB2, complete with an ER-Diagram, queries, views, modifications, stored procedures, indices, and JDBC interface.

**Application Background**
The database application models a car rental company that has numerous branches and manages various cars of different models. The rental company rents cars to customers (renters), offers optional insurance during the rentals and also tracks fines and repairs. The database is designed to also maintain information about the employees, including mechanics and managers that are responsible for the repairs and fines respectively. It is designed to support the storage, retrieval and management of data related to rentals, customers, vehicles, insurance plans, repairs, employees and penalty fines.

**System Capabilities**
The system features an interactive Java/JDBC CLI interface and automated database tasks via stored procedures.
